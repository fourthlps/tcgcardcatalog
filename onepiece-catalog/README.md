# Voyage Log — One Piece TCG Catalog (เวอร์ชันใช้งานได้จริง)

## วิธีติดตั้ง

1. ในโฟลเดอร์เดียวกับ `index.html` ให้สร้างโฟลเดอร์ชื่อ `data/one_piece/`
2. ย้ายไฟล์ 15 ไฟล์ที่ดาวน์โหลดจากเบราว์เซอร์เมื่อกี้ (OP-01.json ถึง OP-13.json,
   OP-16.json และ index.json) ไปใส่ในโฟลเดอร์ `data/one_piece/` นั้น

โครงสร้างควรหน้าตาแบบนี้:
```
onepiece-catalog/
├── index.html
└── data/
    └── one_piece/
        ├── index.json
        ├── OP-01.json
        ├── OP-02.json
        ├── ...
        └── OP-16.json
```

## วิธีรัน (สำคัญ — เปิดไฟล์ตรงๆ ไม่ได้)

เบราว์เซอร์บล็อกการ `fetch()` ไฟล์ในเครื่องโดยตรง (`file://`) ด้วยเหตุผลความ
ปลอดภัย เพราะงั้น double-click เปิด index.html เฉยๆ จะไม่โหลดข้อมูล ต้องรันผ่าน
local server เล็กๆ ก่อน:

**ถ้ามี Python ในเครื่อง** เปิด terminal ในโฟลเดอร์ `onepiece-catalog/` แล้วพิมพ์:
```
python -m http.server 8000
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8000`

**ถ้าใช้ VS Code** ติดตั้งส่วนเสริม "Live Server" แล้วคลิกขวาที่ `index.html`
เลือก "Open with Live Server"

## มีอะไรในนี้

- ครอบคลุม OP-01 ถึง OP-13 และ OP-16 (14 ชุด, 2,174 ใบ) พร้อมราคาจริง
- คลิกชุด → เห็นการ์ดทั้งหมด → คลิกการ์ด → เห็นราคาตลาด + ราคาอ้างอิง + รูปจริง
- มีช่องค้นหาชื่อการ์ดในแต่ละชุด
- Pokémon / Naruto / กล่องสะสม ยังเป็นปุ่ม placeholder รอข้อมูล

## ที่ยังไม่มี (ตามที่คุยกันไว้)

- OP14-EB04, OP15-EB04 และ Extra Booster / Starter Deck / Premium Booster อื่นๆ —
  ยังไม่ได้ดึงมา (รอตัดสินใจว่าจะรวมเข้าระบบไหม)
- ราคายังเป็น snapshot ครั้งเดียว ยังไม่มีการอัปเดตอัตโนมัติรายวัน
- ยังไม่มี database จริง (Supabase ฯลฯ) — ตอนนี้อ่านจากไฟล์ JSON ตรงๆ
